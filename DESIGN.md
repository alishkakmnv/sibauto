# DESIGN.md — СибАвтоПрокат (Tesla-inspired)

> Философия: **радикальное вычитание**. Полноэкранная фотография авто, near-zero UI,
> чёрно-белая база, единственный акцент. Ничего лишнего. Каждый экран — как разворот
> Tesla.com: огромное фото машины, короткий заголовок, две кнопки, тишина вокруг.
> Это анти-slop: пусто, дорого, уверенно.

---

## 1. Visual Theme & Atmosphere
- **Настроение:** премиум, спокойствие, уверенность. Не «дёшево», а «дорого за разумные деньги».
- **Плотность:** максимально низкая. Много воздуха. Один смысловой блок на экран.
- **Философия:** subtraction — убираем всё, что не двигает к брони. Фото говорит громче текста.
- **Референс:** Tesla.com — full-viewport фото авто, текст поверх, минимум хрома.

## 2. Color Palette & Roles
| Токен | Hex | Роль |
|---|---|---|
| `--bg` | `#0A0A0A` | основной фон (near-black) |
| `--bg-elevated` | `#141414` | карточки, поднятые поверхности |
| `--surface` | `#1C1C1C` | инпуты, вторичные блоки |
| `--fg` | `#FFFFFF` | основной текст |
| `--fg-muted` | `#A1A1A1` | вторичный текст, подписи |
| `--fg-subtle` | `#6B6B6B` | плейсхолдеры, disabled |
| `--border` | `#2A2A2A` | тонкие разделители |
| `--accent` | `#E31937` | ЕДИНСТВЕННЫЙ акцент (Tesla-red). Только CTA и цена. |
| `--accent-hover` | `#C4152F` | ховер акцента |
| `--light-band` | `#F5F5F5` | светлая секция (чередование, как у Tesla) |
| `--light-band-fg` | `#0A0A0A` | текст на светлой полосе |

**Правило акцента:** красный используется ТОЛЬКО для главной CTA и цены. Больше нигде.
Никаких градиентов, неона, фиолетового. Чёрное/белое + одна красная точка.

## 3. Typography Rules
- **Шрифт:** один гротеск. Inter или Manrope (близко к Tesla Gotham). Никаких засечек.
- **Приём:** большой контраст размеров — огромный display поверх фото, мелкие подписи.

| Уровень | Размер (desktop) | Вес | Применение |
|---|---|---|---|
| Display | 72–96px | 500–600 | заголовок героя поверх фото |
| H1 | 48px | 600 | заголовки секций |
| H2 | 32px | 600 | подзаголовки |
| H3 | 22px | 500 | название авто в карточке |
| Body | 16–18px | 400 | текст |
| Caption | 13–14px | 400 | подписи, юр. текст |
| Price | 40–56px | 600 | цена (акцент) |

- Заголовки: tight letter-spacing (-0.02em), плотный трекинг как у Tesla.
- Uppercase только для мелких лейблов/eyebrow (напр. «КРУГЛОСУТОЧНО»).

## 4. Component Stylings
**Кнопки (Tesla-pill):**
- Primary: заливка `--fg` (белая) или `--accent` (красная) на тёмном фоне, текст контрастный, border-radius 4px (Tesla — почти прямоугольные, чуть скруглённые), padding 14×32, uppercase, letter-spacing 0.05em.
- Secondary: прозрачная, border 1px `--fg`, текст белый. На светлой полосе — инверсия.
- Ширина на мобилке — full-width, стопкой.

**Карточка авто:**
- Фон `--bg-elevated`, border 1px `--border`, radius 8px.
- Фото авто — доминанта карточки (60%+ высоты), объект как на Tesla-конфигураторе.
- Под фото: название (H3), год (caption muted), цена «от N ₽/сут» (accent), кнопка «Подробнее».
- Ховер: лёгкий подъём (translateY -4px), плавно, 250ms ease.

**Инпуты (калькулятор):**
- Фон `--surface`, border 1px `--border`, focus — border `--fg`.
- Date-picker минималистичный, крупные тап-зоны.

**Навигация:**
- Прозрачная поверх героя, при скролле — `--bg` с тонким `--border` снизу.
- Логотип слева, телефон + «Забронировать» справа. На мобилке — бургер.

## 5. Layout Principles
- **Full-viewport секции:** каждый крупный блок ≈ 100vh, фото на весь экран, текст поверх.
- **Чередование:** тёмная секция → светлая полоса (`--light-band`) → тёмная. Как Tesla.
- **Сетка:** каталог — 2 колонки (desktop), 1 (мобилка). Много gap (24–32px).
- **Отступы:** щедрые. Секции padding 96–128px по вертикали (desktop).
- **Контейнер:** max-width 1200px, но фото-секции — full-bleed (край в край).
- **Правило:** один экран = одно сообщение + одно действие.

## 6. Depth & Elevation
- Тени почти нет — плоскость, как у Tesla. Глубина создаётся фото и контрастом, не тенями.
- Если тень нужна: `0 8px 32px rgba(0,0,0,0.4)`, очень мягко, только на карточках при ховере.
- Разделение слоёв — через изменение фона (`--bg` → `--bg-elevated`), не через border/shadow.

## 7. Do's and Don'ts
**DO:**
- Полноэкранные фото авто высокого качества.
- Много пустого пространства.
- Один акцентный цвет, редко.
- Короткие заголовки (2–5 слов).
- Крупная типографика поверх фото.

**DON'T:**
- Градиенты, неон, фиолетовый/индиго (это AI-slop).
- Больше одного акцента.
- Плотные сетки, забитые текстом экраны.
- Мелкие кнопки, скученные элементы.
- Стоковые «бизнес-люди с ноутбуком». Только авто.
- Тяжёлые тени и рамки повсюду.

## 8. Responsive Behavior
- Брейкпоинты: 640 / 768 / 1024 / 1280.
- Тач-зоны минимум 44×44px.
- Full-viewport героя на мобилке — фото сверху, текст под ним (не поверх, если нечитаемо).
- Каталог: 2 кол → 1 кол на <768px.
- Кнопки в героя — стопкой, full-width на мобилке.
- Калькулятор на мобилке — вертикальный, крупные поля дат.

## 9. Agent Prompt Guide
**Быстрый референс:**
- Фон near-black `#0A0A0A`, текст белый, акцент красный `#E31937` (только CTA/цена).
- Шрифт Inter/Manrope, tight tracking, крупный display.
- Full-viewport фото-секции, чередование тёмное/светлое.
- Near-zero UI: минимум элементов, максимум воздуха.

**Готовый промпт:**
> «Собери секцию в эстетике Tesla.com: near-black фон, full-viewport фото авто,
> крупный display-заголовок (2–4 слова) поверх, одна белая и одна красная pill-кнопка,
> много пустого пространства, никаких градиентов и теней. Акцентный красный только
> на CTA. Следуй DESIGN.md.»
