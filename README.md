# СибАвтоПрокат — демо-сайт

Демо-версия сайта аренды авто в Красноярске. Собрана по двум документам в корне репозитория:

- [`STRATEGY.md`](./STRATEGY.md) — маркетинг, структура, тех-план, данные клиента (тарифы, контакты).
- [`DESIGN.md`](./DESIGN.md) — дизайн-система: near-black база, единственный красный акцент, full-viewport фото, near-zero UI.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # прод-сборка
npm run lint
```

## Структура

```
src/
├── app/                    маршруты (App Router)
│   ├── cars/[slug]/        карточка авто
│   ├── how/ contacts/ privacy/
├── components/
│   ├── booking/            контекст + модалка заявки
│   ├── sections/           секции главной
│   ├── layout/             шапка, подвал, шапка внутренних страниц
│   └── ui/                 кнопки, поля, scroll-reveal
├── data/cars.ts            парк и тарифы  ← в бою уезжает в Supabase
└── lib/
    ├── pricing.ts          подбор тарифа, расчёт суммы, форматирование
    └── site.ts             реквизиты клиента (телефон, адрес, залог)
```

## Ключевые места для правок

- **Цены и парк** — `src/data/cars.ts`. Тарифные ступени: `1-3 / 4-7 / 8-15 / 16-29 / 30+`.
- **Контакты, залог, ссылки** — `src/lib/site.ts`.
- **Логика расчёта** — `src/lib/pricing.ts` (`tierForDays`, `quote`).

## Изображения

Фотографии в `public/cars/` — иллюстративные, из открытых источников (Wikimedia Commons,
Openverse). Модели соответствуют реальному парку. Исходники лежат в `scripts/raw`,
обработка — единый грейд под тёмную палитру:

```bash
node scripts/prepare-images.mjs
```

В боевой версии сюда встают снимки реального парка Дениса (или 29 фото из карточки 2ГИС).

## Скриншоты для проверки вёрстки

```bash
node scripts/shots.mjs http://localhost:3000 .shots
```

Снимает главные страницы в desktop и mobile, печатает ошибки консоли.
